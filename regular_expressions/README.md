# Regular Expressions

This project focuses on using **regular expressions (regex)** with **Oniguruma**, the regex library used by Ruby by default.

## Requirements

* OS: Ubuntu 20.04 LTS
* Editors: `vi`, `vim`, `emacs`
* All files must end with a new line
* All Ruby scripts must be executable
* Every Ruby script must start with:

  ```ruby
  #!/usr/bin/env ruby
  ```
* All regex must be compatible with **Oniguruma**
* A `README.md` file is required at the root of the project

## Running the Scripts

Each script accepts one argument:

```bash
./0-simply_match_school.rb "Best School"
```

Make scripts executable with:

```bash
chmod +x *.rb
```
